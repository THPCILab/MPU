# Fig5.e: confusion matrices at 90% sharing

The CSV preserves integer counts and row-normalized fractions for both sharing
modes and all three tasks. Values in the legacy MATLAB export are normalized
percentages, as indicated by its variable names.
Rows are true labels and columns predicted labels.
Fractions retain the six-decimal precision of the archived JSON, so row sums
may differ slightly from one in the final displayed decimal places.
Task IDs are 0=Digits, 1=Uppercase, 2=Lowercase.

# Figure 4 source data

- **Fig4.a:** chip photograph; no numerical data table.
- **Fig4.c:** four confusion matrices, transcribed from the integer annotations
  in the supplied final figure. Rows are true labels and columns predicted labels.
  The CSV stores all 64 cell counts; the summary CSV contains their totals and
  diagonal-derived accuracies. No per-sample predictions are inferred.

Fig4.b curve data are not included in this source-data addition. The available
notebook training histories have not been matched to the plotted traces.
They are not substituted for the figure's source data.

The image filename and SHA-256 of the transcribed source are recorded in
`data/fig4/fig4.c_confusion_counts.json`.
